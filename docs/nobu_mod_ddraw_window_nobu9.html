嵐世記をウィンドウモードで起動する

動作環境

  • Windows 10 以上
    (管理人の動作確認は Windows 11 のみ)
  • DVD版等、古いバージョンで動作するかは不明（原理的には動作しますが未確認）

ダウンロード

更新日 %(year)04d/%(mon)02d/%(mday)02d
ddraw.zip v7.1.0
ダウンロードした後、解凍する前に、zipを「ブロック解除(or 許可する)」必須

zipを解凍する際には、「プロパティ」から「ブロック解除(or 許可する)」してください。
「プロパティ」に「ブロック解除(or 許可する)」といった項目が無いようならこの作業は不要です。

嵐世記ゲームのフォルダーへファイル群をコピー

ゲーム本体のファイルが上書きされたりはしません。
(ゲーム本体のファイル名とは被っていない)

解像度の変更

ddraw.ini をテキストエディタで開いて、以下の項目を変更してください。
嵐世記はアスペクト比が4:3で固定です。
下記は「横1200ピクセル、縦900ピクセル」の例です。

ddraw.ini 
[ddraw]
width=1200
height=900
